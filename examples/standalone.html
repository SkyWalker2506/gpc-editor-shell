EditorShell — Standalone

Demonstrates a fully custom topbar (tabs, brand, accent) for a non-golf project.

EditorShell.mount({
  page: 'maps',
  title: 'Map Editor',
  brand: { name: 'My Roguelike Toolkit', logo: '🗺️', accent: '#5cf2a3' },
  tabs: [
    { page: 'maps',    label: 'Maps',    icon: '🗺️', href: '#maps' },
    { page: 'enemies', label: 'Enemies', icon: '👹', href: '#enemies' },
    { page: 'loot',    label: 'Loot',    icon: '💎', href: '#loot' },
  ],
  actions: {
    onSave:    () => log('SAVE'),
    onPublish: () => log('PUBLISH'),
    onUndo:    () => log('UNDO'),
  }
});

Try the topbar buttons above. Press ? for shortcuts help.
